## 1. デザイン原則

1. **モバイルファースト** — 主要ユーザーはスマホ。片手・親指操作を前提にする(下部タブ、大きなタップ領域)。
2. **セクションで区切る、縦に流す** — 「見出し → カード群 → 「一覧 >」」を1ブロックとして縦にスタック。ユーザーはスクロールで比較・発見する。
3. **サムネイル主導・テキストは短く** — 画像+太字タイトル+1行説明。長文は省略記号で切る。
4. **お得情報は目立たせる** — 割引・キャンペーン・ポイントは専用アクセント色とバッジで強調。
5. **安心感と清潔感** — 落ち着いたネイビー基調。過度に扇情的な表現は避け、信頼できる情報ポータルとして見せる。
6. **一貫性** — 余白・角丸・タイポは下記トークンのみ使用する。
7. **詳細ページは「知る → 比べる → 動く」の順** — ファーストビューで店舗・セラピストの魅力と主要CTAを提示し、スクロールに応じて詳細情報を深掘りさせ、最後に関連コンテンツへ回遊させる。

### 3.2 ブレークポイント

| 名称 | 幅 | 挙動 |
|---|---|---|
| `sm` | ~599px | 基本(下部タブ、2列グリッド) |

| `lg` | 1024px~ | 上部グローバルナビに切替、4〜5列グリッド、左サイドに絞り込み(詳細ページは §3.4 の2カラム) |

### 3.3 詳細ページの区切りルール

- 詳細ページは **区切りの強さを3段階**で使い分ける。

| 強さ | スタイル | 使う場所 |
|---|---|---|
| 強 | 4px `--color-primary` の太線 | 店舗ヘッダー情報 → セラピスト一覧など、**主役コンテンツの開始位置** |
| 中 | `--border-section`(2px グレー) | CTA群 → 「おすすめ」など、**性質の違う大ブロック間** |
| 弱 | 1px `--color-border` | リスト行同士、テーブル行同士 |

## 4. コンポーネント

### 4.1 App Bar(ヘッダー)

- 高さ 56px、背景 `--color-primary`、固定表示。
- 中央: ロゴ(白)。右: 検索アイコン(白・24px、タップ領域 44px)。左: 必要時のみ戻る/メニュー。
- ステータスバー領域も同色で塗る(`theme-color` メタタグを `#1B2F8F` に設定)。
- 詳細ページ用のバリエーションは **4.13 Detail App Bar** を参照。

### 4.2 Bottom Tab Bar

| 位置 | ラベル(案) | 役割 |
|---|---|---|
| 1 | TOP | ホーム |
| 2 | 店舗を探す | エリア・条件検索 |
| 3 | ランキング | 人気店・人気セラピスト |
| 4 | お気に入り | 保存した店舗(マガポケの「本棚」相当) |
| 5 | マイページ | 会員情報・履歴・ポイント |

- 背景白、上に 1px `--color-border`。高さ 64px + `env(safe-area-inset-bottom)`。
- アイコンは **アウトライン 24px**。アクティブ時のみ `--color-primary` に塗り替え + ラベルも同色。非アクティブは `--color-text-sub`。
- ラベルは常時表示(11px)。
- **お気に入りの記号は「★」に統一**する(マガポケのお気に入り/星と同じ。♡は使わない)。
- 詳細ページでもタブバーは **表示したまま**にする(マガポケと同じ)。

### 4.3 Section Header(◆見出し)

```
◆ 大人気の店舗                      一覧 >
──────────────────────────────────────────
```

- 先頭に `--color-primary` の **ひし形(◆ 16px)**、続けて `--font-h2`。
- 右端に `一覧 >` または `もっと見る >`(`--font-title` 13px / primary / 太字 + シェブロン)。
- 見出し下に 1px `--color-border`。
- **セクション同士の間**は高さ 4px の `--color-primary` 太線で区切る。
- 詳細ページの下部セクション(おすすめ等)は **◆なしの見出し(4.21)** を使う。

### 4.4 Card — Grid(2列)

- サムネイル: 比率 **16:9**、`radius-md`、`border-card`、`object-fit: cover`。
- 下に タイトル(`--font-title` / 1行省略)→ 説明(`--font-caption` / グレー / 1行省略)。
- 余白: サムネ〜タイトル 8px、タイトル〜説明 4px。
- 押下時: 不透明度 0.7(アニメ 100ms)。

**店舗カード バリエーション**
- 画像上の左下に **オーバーレイラベル**(4.7)を重ねてよい(例:「新店」「ポータル限定」)。
- 説明文にはエリア + ワンフレーズ(例:「渋谷 / 90分 12,000円〜」)。

### 4.5 Card — Compact(横スクロール)

- 正方形サムネ(約 108×108)、`radius-md`、下にタイトル1行。
- 次のカードが**端で見切れる**幅にして、横スクロールできることを示唆する。
- `scroll-snap-type: x proximity`。スクロールバー非表示。
- 詳細ページの「おすすめ」系は少し大きい **4.21 Recommend Row** を使う。

### 4.6 Ranking List Item

```
┌───┬──────────────────────────────────┐
│[1]│ 店舗名(太字・1行省略)             │
│画像│ 一言説明(グレー・1行)              │
│   │ 特典テキスト(promo色)             │
│   │            👍 25,351   ★ 701,779  │
└───┴──────────────────────────────────┘
```

- サムネイル 130×88(約3:2)、左上に **ランクバッジ**(青い角丸四角 / 白数字 / 24×24)。
- 1〜3位はバッジ色を強調してよい(1位 gold / 2位 silver / 3位 bronze)。4位以降は `--color-primary`。
- 指標は右下に右寄せ。**いいね(赤)/ 星(オレンジ)**。
- 行間は 1px の `--color-border` 区切り、縦パディング 12px。
- リスト末尾に **全幅CTAボタン**「ランキングの続きを見る >」(4.9 Primary Button)。

### 4.7 Badge / Label

| 種類 | スタイル |
|---|---|
| **オーバーレイラベル** | 画像下端に全幅の帯。白 85% 背景 + `--color-primary` の太字 11px。(例:「ポータル限定」) |
| **ピルラベル** | `radius-pill`、背景 `#8A8A8A`、白太字 13px、幅100%も可。(例:「対象は計24店舗!」) |
| **ステータスバッジ** | 営業中 = `--color-success` 背景 / 白文字。受付終了 = グレー。 |
| **ポイント/特典バッジ** | 直径 48px の黄円(`--color-accent-point`)、中央にギフトアイコン + 「5P」。文字色は `--color-text`。 |
| **期間限定** | 画像左上に赤系バッジ「〜12/15まで」を重ねる。 |
| **更新バッジ** | `radius-pill`、背景 `--color-accent-promo`、白太字 11px、padding 4px 10px。(例:「更新」)→ 4.14 で使用 |
| **UPリボン** | サムネ左上の斜めコーナーリボン。背景 `--color-accent-like`、白太字 10px「UP」。→ 4.17 で使用 |

### 4.8 Hero Carousel & Banner

- ヒーロー: 全幅(左右パディングなし)、比率 約 16:10。下部に **ドットインジケーター**(アクティブ = 白、非アクティブ = 白 50%)。
- 自動送り 5秒、スワイプ対応、`prefers-reduced-motion` 時は自動送りを停止。
- ショートカットバナー: 横スクロール、高さ約 100px、`radius-lg`。
- CTAバナー(ポイント獲得等): 全幅、`radius-lg`、高さ 64px。**赤系** = 主要アクション、**緑系** = 無料アクション。右端に指アイコン。
- 詳細ページのヒーローは **4.13 / 6.3** を参照(比率 16:9、自動送りなし)。

### 4.9 Buttons

| 種類 | スタイル |
|---|---|
| **Primary** | 背景 `--color-primary` / 白文字 14px 太字 / 高さ 48px / `radius-md` / 全幅 / 右にシェブロン |
| **Primary Large** | 上記の大型版。高さ `--btn-h-lg`(52px) / `--font-btn`(16px)。詳細ページの主CTA・「まとめ買い」相当 |
| **Outline Large** | 背景白 / `--border-outline` / 文字 `--color-primary` 16px 太字 / 高さ 52px / `radius-md` / 全幅 / **右端に `>` シェブロン**。「全N名を表示する >」等 |
| **Secondary(ボタンカード)** | 背景 `--color-bg-sub` / `radius-lg` / 高さ 60px / 左アイコン + 中央ラベル。2列グリッドで配置(フッターのメニュー等) |
| **Text Link** | `--color-primary` / 太字 / 下線なし。`一覧 >` など |
| **FAB(トップへ戻る)** | 直径 48px の円 / `--color-overlay` / 白い上向き三角 / 下部タブの 16px 上 / 中央配置 / スクロール後に表示 |

- 最小タップ領域は **44×44px**。
- Disabled は不透明度 0.4 + `pointer-events: none`。
- 縦に積むボタン同士の間隔は `--space-2`(8px)。

### 4.10 Tabs(ランキング切替)

- 横スクロール可のテキストタブ。アクティブ = `--color-primary` 太字 + 下に 3px の primary ライン。非アクティブ = `--color-text-sub`。
- 例: 「総合 / 新店 / エリア別 / 口コミ順」。

## 8. アイコン

- スタイル: **アウトライン**、線幅 1.5–2px、24px グリッド、角は丸め。
- 推奨: Lucide / Material Symbols Outlined。
- 色は `currentColor` で継承。装飾のみのアイコンには `aria-hidden="true"`。
- 詳細ページで使う主なアイコン: `chevron-left`(戻る)/ `share-2`(シェア)/ `thumbs-up`(いいね)/ `star`(お気に入り)/ `message-circle`(口コミ数)/ `gift`(特典)/ `coins`(料金)/ `phone`(電話)/ `map-pin`(地図)/ `chevron-right`(遷移)。

---

## 9. 画像ガイドライン

- サムネイルは **用途ごとの比率に統一**して事前クロップ(カード 16:9 / ヒーロー 16:9 / リスト行 2:1・人物 3:4 / セラピスト詳細ビジュアル 3:4 / おすすめ 1:1)。WebP/AVIF、遅延読み込み(`loading="lazy"`。**ヒーロー1枚目は eager + `fetchpriority="high"`**)、`width/height` を必ず指定(CLS防止)。
- 読み込み中は `--color-bg-sub` のスケルトン。
- **掲載NG**: 露骨・性的な表現、未成年を想起させる画像、無断転載画像、過度な加工による誤認を招く写真。
- 人物画像は掲載許諾を得たもののみ。顔出し不可の場合の代替(シルエット / ロゴ)を用意する。
- セラピストのプロフィール項目は掲載ルールに従い **最小限**(名前・一言・出勤状況)とする。

---

## 10. コンテンツ・ライティング規約

- 店舗名・タイトルは太字で簡潔に。説明は **全角30字以内**を目安。
- 価格は **税込 / 時間 / コース名** をセットで表記。
- 強調(promo色)は「割引・特典・期間限定」のみに使う。多用しない。
- 誇大表現(「No.1」「日本一」等)は根拠の明示がない限り使用しない。
- 医療的効果を断定する表現は使用しない。
- 敬体(です・ます)で統一。
- 主CTAの文言は動詞で終える(「電話で予約する」「電話で指名予約する」「コース・料金を見る」「全12名を表示する」)。
- ステータス文言は短く固定: 「出勤中」「空き」「休み」「満席」「クーポン」。

---

## 11. アクセシビリティ

- コントラスト比: 本文 4.5:1 以上(グレー `#888` は白背景で約 3.5:1 のため、**12px 以下の重要情報には使わない**。重要な補足は `#666` 以上)。
- 色だけで状態を示さない(営業中は色 + テキスト、ステータス丸も必ずテキスト併記)。
- 黄色(`--color-accent-point`)の上の文字は `--color-text` のみ(白文字は不可)。
- フォーカスリングは `2px solid var(--color-primary)` + オフセット 2px。
- 画像には `alt`(店舗名)を付与。装飾画像は `alt=""`。
- `prefers-reduced-motion` を尊重する。
- アクション丸ボタン(いいね/お気に入り)は `aria-pressed` を持たせ、数値変化を `aria-live="polite"` で通知する。
- 透明ヘッダー上のアイコンは `--color-scrim` の丸背景で 3:1 以上のコントラストを確保する。
- ピンチズームを **禁止しない**(`viewport` に `maximum-scale` / `user-scalable=no` を入れない)。

## 13. 法務・運用上の注意(デザイン要件として)

- 年齢確認(18歳以上)の導線を設ける。
- 掲載店舗の**届出状況・所在地・運営者情報**を確認・表示できる欄を店舗詳細(4.23 Info Table)に持たせる。**届出情報が未確認の店舗は「未確認」と明示**する。
- **PR表記の明確化**: 広告枠・PR掲載箇所には必ず 4.28 のPRラベル・帯を付与し、ステマ規制に完全準拠する(おすすめ枠に広告が混ざる場合は、カード左上に「PR」ラベル)。
- 口コミは投稿規約・削除基準・ステマ対策(関係者投稿の禁止)を整備し、詳細ページからリンクする。
- 各種広告規制・景品表示法・風営法関連の表現ルールは、公開前に専門家へ確認すること。

## 14. 実装メモ

- 推奨: CSS変数 + Tailwind(`theme.extend` にトークンを登録)、またはCSS Modules。
- コンポーネント命名: `SectionHeader`, `CardGrid`, `CardCompact`, `RankingItem`, `Badge`, `TabBar`, `AppBar`, `Fab`, `HeroCarousel`。
- **v1.1 追加**: `DetailAppBar`, `NoticeStrip`, `StatActionRow`, `ShopTitleBlock`, `OutlineChip`, `ListRow`, `StatusCircle`, `StickyCtaBar`, `RecommendRow`, `CouponFab`, `InfoTable`, `PriceTable`, `OutlineButton`。
- **v1.2 追加**: `ProfileHeader`, `ScheduleGrid`, `ReviewCard`, `PrLabel`。
- 各コンポーネントはトークン以外の値をハードコードしない。
- `DetailAppBar` は `IntersectionObserver`(ヒーロー下端の番兵要素)で切り替える。`scroll` イベントの直接監視は避ける。
- `StickyCtaBar` も主CTAを `IntersectionObserver` で監視する。
- Next.js の場合: 詳細ページは `app/shops/[id]/page.tsx`(Server Component)で店舗データを取得し、いいね/お気に入り・ヘッダー切替・Sticky CTA・FABなど**操作を持つ部品だけ** Client Component にする。
- 画像は `next/image`。外部ドメインを使う場合は `next.config` の `images.remotePatterns` に登録する。
